## Flujo de trabajo
Cada estudiante trabajó en su propia rama.
Los cambios fueron integrados mediante Pull Requests
y revisión cruzada.

## Resolución de conflictos
Durante la integración se produjo un conflicto
en archivos HTML y CSS debido a modificaciones
realizadas por ambos estudiantes.

El conflicto fue resuelto manualmente y registrado
mediante un commit de resolución.

## Validación
Se validaron los archivos HTML y CSS y se corrigieron
los errores encontrados.

## Reflexión colaborativa
El proyecto permitió practicar el trabajo colaborativo
con ramas, commits, Pull Requests, revisiones y
resolución de conflictos.
